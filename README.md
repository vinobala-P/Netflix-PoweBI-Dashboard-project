# 🎬 Netflix Data Dashboard — Power BI Project

An interactive Power BI dashboard analyzing Netflix's content catalog — exploring trends across genres, release years, ratings, and more.

## 📋 Overview

This project uses Power BI to visualize and explore a Netflix dataset, turning raw data into interactive charts and insights. It's built to showcase data visualization, DAX measures, and dashboard design skills.

## 📊 What's Inside

- `Netflix_data.pbix` — the full Power BI project file, including data model, visuals, and dashboard pages

## 🛠️ Tech Stack

- **Tool:** Microsoft Power BI Desktop
- **Data Source:** Netflix content dataset

## 🚀 How to View

1. Download [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free) if you don't already have it.
2. Download the `Netflix_data.pbix` file from this repository.
3. Open it in Power BI Desktop to explore the interactive dashboard — filter by genre, year, rating, and more.

## 🎯 What This Project Demonstrates

- Data cleaning and modeling in Power BI
- Interactive dashboard design
- Visual storytelling with real-world data
